# Wi-Fi Changer

2つの Wi-Fi をワンタップで切り替えるだけのアプリです（SwiftUI、iOS 17 以降）。
設定アプリの Wi-Fi 画面のような見た目で、ホーム画面・ロック画面のウィジェットから切り替えられます。

## できること

- ネットワーク A・B に名前・SSID・パスワード・アイコンを登録（パスワードはキーチェーンに保存）
- 行をタップでそのネットワークに接続、「もう一方に切り替える」で入れ替え
- ウィジェット
  | サイズ | タップしたとき |
  |---|---|
  | 小 | もう一方に切り替え（いまの接続先と、切り替え先を表示） |
  | 中 | 押したほうに接続（コントロールセンター風の2つのボタン） |
  | ロック画面（円・長方形・1行） | もう一方に切り替え |

ウィジェットには**いま接続しているWi-Fiの名前**が出ます。アプリの「位置情報を許可」をオンにすると（iOS では Wi-Fi 名の取得に位置情報の許可が必要）、コントロールセンターで切り替えたときや、登録していない Wi-Fi・未接続のときもウィジェット自身が読み取って表示します（更新は iOS 任せで、数分〜十数分遅れることがあります）。許可しない場合は、アプリで最後に切り替えた・確認した接続先を表示します。

ウィジェットをタップすると一瞬アプリが開いて切り替え、終わるとホーム画面に戻ります（設定でオフにできます）。
iOS では Wi-Fi の接続はアプリが前面にあるときしかできないため、アプリを開かずに切り替えることはできません。

## 使い方のポイント

- **設定アプリで保存済みの Wi-Fi は切り替えられません。** 先に 設定 › Wi-Fi で、そのネットワークの ⓘ →「このネットワーク設定を削除」をしてから、アプリで登録して接続してください。
- 初めて接続するときは「“Wi-Fi Changer”がWi-Fiネットワーク“…”に接続しようとしています」と確認が出るので「接続」を選びます。
- 対応しているのは WPA/WPA2/WPA3 パーソナル（パスワード1つ）と、パスワードなしのネットワークです。大学などのユーザー名＋パスワードで入るネットワーク（エンタープライズ）には対応していません。
- アプリを削除すると、アプリで登録した Wi-Fi も iPhone から消えます。

## 署名について

Wi-Fi の切り替えには **Hotspot Configuration**（`com.apple.developer.networking.HotspotConfiguration`）の権限が必要です。署名ツールで署名するときに、この権限が入るようにしてください。入っていないと、接続しようとしたときに「Wi-Fiを切り替えられません」と出ます。
Wi-Fi 名の読み取りには **Access Wi-Fi Information**（`com.apple.developer.networking.wifi-info`）の権限も使います（アプリとウィジェットの両方）。入っていなくても切り替えはできますが、ウィジェットの表示はアプリで記録した接続先だけになります。

ウィジェットとのデータ共有は、署名に App Group（`group.app.wifichanger`）が入っていればそれを使います。入っていない場合は StudyPlan・MoneyPlan と同じように、**カレンダーの 2001年1月4日に設定のメモを1件だけ**保存してウィジェットに渡します（パスワードは入れません）。アプリの「カレンダーへのアクセスを許可」をタップしてください。

## IPA の作り方（Mac 不要）

`main` に push すると、GitHub Actions（`.github/workflows/ios.yml`）が自動でビルドします。手動で動かすときは **Actions** タブ →「iOS Build」→「Run workflow」。

1. 完了した実行を開き、下の **Artifacts** から `WiFiChanger-unsigned-番号.ipa` をダウンロード
2. 普段使っている署名ツールで署名してインストール

見本データでの各画面のスクリーンショットは `ci-screenshots` ブランチに置かれます。

## 構成

```
Shared/              設定・保存・ウィジェットの表示（アプリとウィジェットで共通）
WiFiChanger/         アプリ本体（SwiftUI）。切り替えは App/WiFiSwitcher.swift
WiFiChangerWidget/   ウィジェット（WidgetKit）
tools/icon.py        アイコンを作るスクリプト
project.yml          XcodeGen の設定（Xcode プロジェクトはビルド時に作る）
```
